Install

安装与部署

服务会自动注册路由与配置，页面与静态资源均无需复制到主项目。

01

安装扩展

在主项目执行 composer require youvision/think-store，think-view 会随依赖自动安装。

02

注册服务

执行 php think service:discover 与 php think vendor:publish，路由与配置随即生效。

03

打开管理页

访问 /store 查看已安装的 think-store-* 发布包。

04

静态资源

layui 与样式由 /store/assets/<path> 直接输出，无需发布到 public。

Endpoints

接口说明

全部路由由 Youvision\ThinkStore\Service 在 boot 阶段加载。

GET/store/packages

查询已安装的 youvision/think-store-* 发布包，返回 total 与 packages，每个包含 home 首页路由。

GET/store

渲染发布包管理页，使用 think-view 的 Think 驱动与包内 theme/view 模板。

GET/store/intro

渲染当前使用说明页，适合作为接入文档或内部说明入口。

GET/store/assets/<path>

输出包内 theme/assets，路径经过 realpath 校验并拒绝 ..，避免目录穿越。

修改 config/store.php 的 route.prefix 后，页面内的接口与资源地址会自动跟随。
Config

配置项

包内默认配置会与主项目配置合并，项目侧配置优先。

route.enabled 默认 true。是否注册内置页面、查询与资源路由；关闭后由主项目自行注册。
route.prefix 默认 store。路由前缀，留空表示不添加前缀。
route.middleware 默认 []。应用到整组路由的中间件，生产环境建议配置登录鉴权。
prefix 默认 youvision/think-store-。只有包名匹配该前缀的 Composer 包才会被识别。
exclude 默认 []。需要跳过的包名，支持 *、? 通配符。
Security

安全建议

查询接口会暴露包名、版本与安装目录，生产环境请按需限制访问。

  • 为 route.middleware 配置登录鉴权中间件，避免安装路径与版本信息对外暴露。
  • 资源路由只读取包内 theme/assets，已拒绝目录穿越；不要在主项目额外放行任意文件读取。
  • 模板与静态资源均位于包内，升级扩展后可随 Composer 一起更新，无需手工同步。
  • 安装或移除发布包后，刷新管理页即可获取最新列表。
