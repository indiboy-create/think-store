管理页如何工作

管理页由 think-view 渲染，读取 youvision/think-store 的查询接口，并用数据表格展示主项目中已安装的发布包。

  • 功能说明
  • 部署流程
  • 接口与配置
  • 安全建议
  • 发布包：包名与包内 composer.json 的描述。
  • 版本：Composer 已安装版本。
  • 安装目录：Composer 安装该包的绝对路径。
  • 列表只读取已安装包的信息，不会写入或修改任何文件。
  1. 主项目执行 composer require youvision/think-store，think-view 会随依赖自动安装。
  2. 执行 php think service:discover 与 php think vendor:publish 注册服务并发布配置。
  3. 静态资源由 /store/assets/<path> 路由直接读取包内 theme/assets 输出，无需复制到 public。
  4. 安装 youvision/think-store-example 等发布包后，刷新本页查看包列表。
  5. 访问 /store/think-store 打开管理页，访问 /store/think-store/intro 查看本说明。

页面由 think-view 直接渲染，模板位于包内 theme/view；静态资源由 assets 路由输出，均无需发布到 public。

  • GET /store/think-store：渲染发布包管理页。
  • GET /store/think-store/intro：渲染使用说明页。
  • GET /store/packages：查询已安装的 youvision/think-store-* 发布包。
  • GET /store/assets/<path>：直接输出包内 theme/assets 的 layui 与样式文件。
  • route.prefix：默认 store，页面路由与接口路由均受该前缀控制。
  • prefix：默认 youvision/think-store-，决定哪些 Composer 包会被识别为发布包。
  • exclude：需要跳过的包名，支持 *、? 通配符。
# 查询
curl http://127.0.0.1:8000/store/packages

# 管理页
curl http://127.0.0.1:8000/store/think-store
  • 查询接口会暴露已安装包的名称、版本与安装路径，生产环境建议通过中间件限制访问权限。
  • 页面路由同样应用 route.middleware，可按需加入登录校验。
  • 不要在前端页面展示敏感目录结构，必要时为接口配置鉴权中间件。
  • 安装或移除发布包后，刷新本页即可获取最新列表。
